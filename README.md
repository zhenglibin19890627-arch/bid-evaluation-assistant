# 投标机会评估助手（bid-evaluation-assistant）

面向零代码用户的**政府采购投标机会评估**工具：从浙江政府采购网按地市自动采集公告 → 20 大类×52 子类自动初筛 → 政采云自动下载招标文件 → AI 逐项研判"适不适合参标、为什么"，输出初筛结果 Excel 与研判报告 Markdown。

> 本项目为 **Skill（`SKILL.md`）+ 本地 Python 脚本** 混合形态：文件解析与初筛交给脚本，AI 研判由对话中的大模型执行。纯对话式交互，无需 Widget。

## 核心能力

- **公告采集（增量）**：按地市从浙江政府采购网采集 9 类公告，`collect_round.py` 按各城市 Sheet 最后公告时间起算增量补采、2 天一批自动拆批、URL 去重合并；
- **自动初筛**：时间窗口（可选）+ 公告类型 + 项目类型（20 大类 × 52 子类五级匹配，无"未分类"兜底）+ 相关性软标记（不误杀，由 AI 人工确认）；
- **增量机制**：以公告 URL 为唯一键记录初筛/研判状态，每天只处理新增，"开始研判"永不重复；
- **标书自动下载**：浏览器登录态复用（`browser_login.py`，密码不经手、不落盘），`fetch_bid_docs.py` 从政采云自动申请获取并下载招标文件，自动维护 `标书映射.json`；
- **AI 研判框架**：资格条件硬门槛核对 → 评分客观分扣分核算（确定扣分 >2 分不建议参加，条款逐字引用）→ 提示，结论先行；
- **轻量交付**：初筛结果回写主文件/导出 Excel，研判报告 Markdown，一键分享协作。

## 目录结构

```
├── SKILL.md                # 技能入口（触发条件、工作流、研判框架）
├── 说明.md                  # 零代码用户使用说明
├── scripts/                # 核心脚本（无第三方 AI 依赖，纯本地）
│   ├── collect_round.py    # 增量采集编排（多 Sheet 主文件）
│   ├── fetch_zfcg.py       # 浙江政府采购网采集器（API+HTML+正则+交叉引用）
│   ├── merge_to_main.py    # 批次合并入主文件（URL 去重、状态列）
│   ├── analyze_main.py     # 主文件缺失日期分析
│   ├── run_pipeline.py     # 一键流水线：初筛+标书匹配+评分章节提取
│   ├── excel_tool.py       # Excel 读取/初筛过滤/20大类×52子类分类引擎
│   ├── status_tool.py      # 初筛/研判状态双轨读写（增量机制核心）
│   ├── docx_parser.py      # 标书解析（.docx/.doc/.pdf）+评分章节提取
│   ├── company_profile.py  # 企业资料摘要与占位词校验
│   ├── bid_mapping.py      # 标书↔项目手动映射
│   ├── browser_login.py    # 政采云登录（Playwright 持久化档案）
│   └── fetch_bid_docs.py   # 招标文件自动下载（签名直链）
├── references/             # 地市配置、API 规格、抽取规则等参考
├── tests/smoke_test.py     # 合成数据冒烟测试（11 项检查）
└── legacy/                 # 历史遗留的一次性脚本（不参与工作流）
```

## 快速开始

1. **安装依赖**：`pip install -r requirements.txt`（可选下载功能：`pip install -r requirements_download.txt`，浏览器用系统 Edge，零下载）；
2. **准备三个文件夹**（位置任意）：清单路径（投标机会清单 .xlsx，或由采集生成）、标书路径（.docx/.doc/.pdf）、公司资料路径（公司介绍.md + 可选业绩表/人员社保表）；
3. **对话开始**：说"采集"（可选，按地市增量采集公告）→ 说"开始研判"（增量初筛 + AI 研判）；
4. **可选登录**：说"登录政采云"，在弹出的浏览器窗口自己登录一次，之后说"下载标书"自动取回招标文件。

详细用法见 `说明.md`；技能完整工作流见 `SKILL.md`。

## 依赖

Python 3.9+，`pandas`、`openpyxl`、`python-docx`、`pdfplumber`；可选 `playwright`（自动下载标书）、`pywin32`（.doc 老格式自动转换）。
